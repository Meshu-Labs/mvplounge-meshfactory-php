# MeshFactory Docs Instructions (Entrypoint)

This file is the docs entrypoint for conventions, indexes, and cross-domain navigation.

## Namespace Summary

MeshFactory builds HTML elements through a layered factory model:

- Enum layer defines element and attribute vocabulary.
- Abstract classes define shared behavior and family contracts.
- Concrete classes implement specific element behavior.
- Attribute handling is the dynamic extension surface.

## Core Concepts

- Shared DOM behavior is centralized in `FactoryAbstract`.
- Element-level behavior is centralized in `FactoryElementAbstract`.
- Naming conventions prioritize predictable inheritance.
- Compatibility is enforced through enum-driven contracts.

## Quick Operational Reminders

- Run PHP quality checks after code edits in namespace-driven domains.
- Run `composer test` (full sandbox suite) before opening a pull request; CI runs it too.
- After adding or changing an element class or sandbox script, run `composer inventory` and commit the regenerated inventory.
- Keep PHP files UTF-8 without BOM.
- Keep abstract classes under `/src/Labs/MeshFactory/Abstract/`.
- Keep concrete implementations under `/src/Labs/MeshFactory/Element/{Domain}/`.
